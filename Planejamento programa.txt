FUNÇÕES DO PROGRAMA

void displayPage(pageNumber):
	Mostra uma tela

void selectPage(currentDisplay, keyPressed):
	Seleciona a pagina com base na tela atual e na tecla pressionada

void moveCursorLeft(currentDisplay):
	Movimenta o cursor para a esquerda com base na tela atual
void moveCursorRight(currentDisplay):
	Movimenta o cursor para a direita com base na tela atual
